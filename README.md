# TENDEN (テンデン)

「日頃の備えと『迷わない』ルートを。」
TENDENは、土地勘のない観光客を対象とした、平時の「減災・備え」と発災時の「避難誘導」をシームレスに繋ぐWebアプリケーション (PWA) です。鎌倉沿岸部（由比ヶ浜・七里ヶ浜・材木座エリア）を対象とする個人研究の公開実験版です。自治体の公式サービスではなく、現地安全性・実利用効果は未検証です。

## 特徴

2026年9月4日の説明訂正では、公開中の200エピソード版の経路データを維持しています。研究で生成した400エピソード版や別条件の評価値を、配信版の性能と混同しません。[配信方策と研究評価の記録](https://masatosprojects.github.io/tenden-app/research-model-notes.html)を参照してください。

*   **PWA (Progressive Web App)**: 設定で利用者が有効にするオプトイン方式です。保存済み資産・閲覧済み地図に限られ、外部API・未取得データ・情報の最新性・全機能のオフライン動作は保証しません。
*   **引き算のデザインとCUD**: 情報過多を防ぐノイズレスなApple-like UI。カラーユニバーサルデザイン（CUD）を採用し、色覚多様性に配慮。
*   **ゼロ・クリック多言語対応**: ブラウザ言語を検知し、30言語の辞書表示を切り替え（日本語・英語・中国語・韓国語など）。
*   **シームレスなモード移行**: 平時（ライトモード・海抜表示）から、テストボタンやP2P地震情報WebSocketトリガーで瞬時に発災時（ダークモード・緊急ルート表示）へ切り替わります。
*   **強化学習ルート（旧称：AIスマート避難ルート）＋ 要配慮者ルート**: 事前計算した線形Q学習の方策をたどる参考経路と、坂コスト付きダイクストラ法による「♿ 要配慮者ルート（緩やかな坂・狭くない道優先）」の2候補から選択可能。さらに分散避難（てんでんこ）により端末ごとにAIルート内でわずかに異なる経路が選ばれ、集中を緩和することを狙う。実社会での分散効果や安全性を保証するものではない。
*   **公式浸水想定タイル**: 国土地理院ハザードマップポータルサイトの津波浸水想定タイルをオーバーレイ表示。
*   **浸水区域リアルタイム判定**: GPS/ピン位置の浸水タイルをCanvasピクセル解析し、「区域内/区域外」をHUDに即表示。
*   **ルート逸脱警告**: 避難ルートから外れた場合、Android（Vibration APIによる振動）やiOS（視覚的フラッシュ）で即座に警告。
*   **安否共有（Web Share API）**: 発災時、ワンタップで現在地のGoogleマップURLと安全を知らせるメッセージを家族や友人に送信可能。

## インストールと起動方法

### ローカルでの実行

Windows環境であれば、付属のバッチファイルで簡単にローカルサーバーを起動できます。
(※ Python 3 がインストールされている必要があります)

1. リポジトリをクローンまたはダウンロードします。
2. `tenden-app/` フォルダ内にある `run.bat` をダブルクリックして実行します。
3. ブラウザで `http://localhost:8080` にアクセスします。

### Docker を使用したデプロイ (Cloud Run 等)

軽量なNginxベースの `Dockerfile` が含まれています。

```bash
cd tenden-app
docker build -t tenden-app .
docker run -p 8080:80 tenden-app
```

### GitHub Pages への自動デプロイ

このリポジトリには `.github/workflows/deploy.yml` が含まれており、`main` ブランチにプッシュするだけで自動的に GitHub Pages へ静的デプロイされる CI/CD 環境が整っています。

## 使用データ・API

| 用途 | データソース |
|---|---|
| 地図タイル | CartoDB (basemaps.cartocdn.com) |
| 津波浸水想定 | 国土地理院 ハザードマップポータルサイト (disaportaldata.gsi.go.jp) |
| 標高取得 | 国土地理院 標高API (cyberjapandata2.gsi.go.jp) |
| 道路ルーティング | OSRM (routing.openstreetmap.de) |
| 津波警報検知 | P2P地震情報 WebSocket (api.p2pquake.net/v2/ws) |
| 避難所・混雑データ | 鎌倉沿岸部の個人研究による事前計算データ（配信資産ごとに版・集計範囲を区別。現地混雑の観測ではない） |

## 3つの基本理念
1. **「絶対の正解」ではなく「最善の選択肢」を**（最終判断はユーザーの目に委ねる）
2. **あなたの「逃げる」が、街全体の命を救う**（分散ルートによるパニック回避）
3. **日常の「知る」を、非常時の「生きる」に変える**（平時の画像保存機能）
